# Hi, I'm Gabi 👋

I'm a **Biologist**, **Environmental Analyst at Equilíbrio Florestal (for Suzano S/A)**, and a **PhD Candidate in Tropical Marine Sciences** at [Labomar](https://labomar.ufc.br/pt).

I develop reproducible workflows and tools for **biodiversity monitoring**, **ecological modeling**, **spatial analysis (GIS)**, and **data science**, with a focus on transforming ecological data into practical solutions for conservation and environmental management.
